# AI News Assistant 📰

An AI-powered news assistant that helps users discover and explore the latest news from around the world.

Users can search for recent news through natural-language queries, explore news by specific topics, or find news related to a particular country, city, or region.

The assistant uses an LLM-powered agent to understand user requests, retrieve relevant news, and provide clear summaries with links to original sources.

## Core Features

- **Live News Search:** Search for the latest news using natural-language queries or questions.
- **News by Topics:** Discover recent news about specific subjects, such as technology, politics, sports, and international affairs.
- **News by Location:** Explore news related to a particular country, city, or region.

## Planned Tech Stack

- **LLM:** GPT-OSS-120B via Groq API
